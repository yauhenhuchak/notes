# Мои заметки: личный аналог Evernote

Работает на Android, Windows и macOS: это одно веб-приложение (PWA), которое ставится как обычная программа.
Без интернета работает, заметки синхронизирует через ваш Dropbox. Свой сервер не нужен.

## Состав

| Файл | Назначение |
|---|---|
| `index.html` | само приложение |
| `manifest.webmanifest`, `icon-*.png` | данные для установки как приложения |
| `sw.js` | офлайн-режим |

## Шаг 1. Выложить на HTTPS (один раз)

Для установки и для входа в Dropbox приложение должно открываться по `https://`. Бесплатные варианты:

- **Netlify Drop**: откройте https://app.netlify.com/drop и перетащите туда папку с этими файлами. Получите адрес вида `https://xxxx.netlify.app/`.
- **GitHub Pages**: создайте репозиторий, загрузите файлы, затем Settings → Pages → Deploy from branch. Адрес будет вида `https://логин.github.io/репозиторий/`.

Заметки на хостинг не попадают. Там лежит только код, а данные хранятся на устройствах и в вашем Dropbox.

## Шаг 2. Подключить Dropbox (один раз)

1. Откройте приложение, затем меню слева → **☁ Dropbox**. В окне будет пошаговая инструкция и адрес (Redirect URI), который нужно скопировать.
2. На https://www.dropbox.com/developers/apps/create выберите Scoped access → App folder.
3. На вкладке Permissions отметьте `files.content.read` и `files.content.write`, нажмите Submit.
4. На вкладке Settings добавьте Redirect URI из окна приложения и проверьте, что «Allow public clients» включено.
5. Скопируйте App key в приложение и нажмите «Подключить Dropbox».

Заметки хранятся в Dropbox в файле `Приложения/<имя приложения>/notes.json`.

## Шаг 3. Установить на устройства

- **Windows / macOS (Chrome или Edge)**: значок «Установить» в адресной строке или кнопка «📲 Установить» в меню.
- **macOS (Safari 17+)**: Файл → «Добавить в Dock».
- **Android (Chrome)**: меню ⋮ → «Установить приложение» / «Добавить на главный экран».

На каждом устройстве один раз подключите Dropbox с **тем же App key**.

## Как работает синхронизация

- Запускается автоматически: через пару секунд после изменения, раз в минуту, при возврате в приложение и при появлении сети. Кнопка ⟳ запускает её вручную.
- Если одна и та же заметка изменена на двух устройствах, остаётся более поздняя правка. Слияние идёт по целым заметкам, а не по строкам внутри них.
- Удаление тоже синхронизируется.
- Картинки хранятся внутри заметок и при вставке уменьшаются до 1600 px. Если картинок очень много, файл синхронизации растёт и синхронизация замедляется.

## Резервные копии

«⬇ Экспорт» сохраняет все заметки в JSON-файл, «⬆ Импорт» загружает их обратно (с объединением). Отдельную заметку можно сохранить в HTML, Markdown или распечатать в PDF.
